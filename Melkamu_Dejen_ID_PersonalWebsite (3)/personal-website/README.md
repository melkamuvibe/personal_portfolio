# Melkamu Dejen - Personal Portfolio Website

Individual assignment for **Internet Programming I (INSY3061)**, Wollo University, Kombolcha Institute of Technology.

## Technologies
HTML5 (semantic elements), CSS3 (variables, grid, flexbox, media queries), vanilla JavaScript. Fonts: Google Fonts (Bricolage Grotesque, Inter). No frameworks.

## Features
- Responsive layout and mobile menu
- Dark/light theme saved with localStorage
- Project filter and details modal
- Animated skill bars
- Contact form with HTML and JavaScript validation
- Downloadable CV link

## Structure
```
index.html
css/style.css
js/script.js
images/profile.jpg
cv/Melkamu_Dejen_CV.pdf   (add the CV here)
```

## How to run
Open `index.html` in any browser. No build step is needed.
